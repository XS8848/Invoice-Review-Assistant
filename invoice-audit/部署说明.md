> 适用环境：Windows 11 + WSL2(Ubuntu 24.04) + conda SF157 + RTX 4070。所有命令本机验证通过。
> 本次升级：数据库 MySQL 8 生产化、凭据随机化加固、一键部署脚本、月累计限额、登录限流、失败重派、批次聚合。

## 二、启动（幂等，可重复执行）

```powershell
# 首次安装 MySQL（只需一次，约 2-5 分钟）
wsl -u root bash -c "tr -d '\r' < /mnt/c/Users/35192/Desktop/test/发票审计系统/invoice-audit/infra/install_mysql.sh | bash"

# 一键部署：MinIO + MySQL + 依赖 + 前端 + 后端 + 健康检查
wsl -e bash -lc "tr -d '\r' < /mnt/c/Users/35192/Desktop/test/发票审计系统/invoice-audit/deploy.sh | bash"

# 日常运维
wsl -e bash -lc "tr -d '\r' < /mnt/c/Users/35192/Desktop/test/发票审计系统/invoice-audit/status.sh | bash"   # 巡检
wsl -e bash -lc "tr -d '\r' < /mnt/c/Users/35192/Desktop/test/发票审计系统/invoice-audit/stop.sh | bash"     # 停后端
```

访问：Windows `http://localhost:8000` · **局域网 `http://192.168.110.194:8000`（当前本机 IP；备用 `http://192.168.110.239:8000`）** · API 文档 `/docs`
审查员：`admin / admin`（首登改密）；员工前端自注册。

> **局域网端口映射（已配置，自动适配 IP 变化）**：8000/9000/9001 经 netsh portproxy 同时监听 192.168.110.194（当前）与 192.168.110.239（备用），转发到 WSL2（connectaddress=127.0.0.1 回环，不受 WSL IP 变化影响）；防火墙入站规则 `InvoiceAudit-8000/9000/9001` 已放行。
> 若本机 IP 再变化（DHCP 续租），重新执行（UAC 授权，自动探测当前 IP）：`powershell -ExecutionPolicy Bypass -File invoice-audit\infra\lan_expose.ps1`
> 原图预签名 URL 通过 `MINIO_PUBLIC_ENDPOINT=192.168.110.194:9000` 生成，局域网浏览器可正常查看（IP 变化时同步改 .env 后重启后端）。

> **WSL 重启后**：`deploy.sh` 一键拉起全部（MinIO/MySQL 无 systemd，脚本幂等处理；MySQL 启动失败会提示先跑 install_mysql.sh）。

## 三、本次升级内容（完善清单）

1. **MySQL 8 生产化**：SQLite → MySQL（`DATABASE_URL` 一行切换，开发可回退 SQLite）
2. **安全加固**：JWT_SECRET/MinIO 凭据随机化并双端同步；登录限流（同工号 1 分钟 5 次→429）；MySQL 专用账号
3. **月累计限额硬拦截**：`per_month_limit` + `per_month_limit_action`(review/reject)，按"当月已报销金额"聚合判定
4. **失败重派**：看板对失败/历史单据一键重派，重新走完整流程（写审计日志）
5. **批次聚合**：员工端历史按批次分组展示；审查员工作区显示同批次其他文件（聚合审查上下文）
6. **worker 并发可配**：`.env` 的 `OCR_WORKERS`(1) / `LLM_WORKERS`(2)
7. **看板表统计**：修复 MySQL 下标识符引号（dialect-aware quoting）

## 七、已知限制

- 照片翻拍/盖章遮挡的增值税票可能漏字段 → 自动转人工（设计行为）
- OCR 串行受 `OCR_WORKERS` 控制（8GB 显存建议 1-2）
- 月累计限额统计口径：当月已报销（result=0）单据金额之和
- MySQL 在 WSL 内无 systemd，WSL 重启后跑 `deploy.sh` 拉起
